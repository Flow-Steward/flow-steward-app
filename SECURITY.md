# Security Policy

## Supported Versions

Security fixes are provided for the latest mainline release and active
maintenance branches.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately.

- Email: security@flow-steward.org
- Include: affected component, impact, reproduction steps, and version/commit.
- Subject prefix: [SECURITY]

If you do not receive an acknowledgement within 3 business days, resend the
report and include "SECURITY" in the subject line.

## Disclosure Process

1. We acknowledge receipt and start triage.
2. We validate impact and assign severity.
3. We prepare and test a fix.
4. We coordinate disclosure timing with reporters when possible.
5. We publish advisory notes after remediation is available.

## Out of Scope

- Requests for support, setup, or configuration help.
- Reports without reproducible technical details.

For general support, use the project support channels on `flow-steward.com`.
