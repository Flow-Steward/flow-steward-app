documented in the operator guide. Configuration audit and outbound HTTP inventory
JSON files are functional contracts, not historical audit reports.

Keep future tasks in the issue tracker. Store disposable verification output
under ignored `logs/` or `audit-artifacts/`, not this tree. Git retains prior
versions; do not duplicate historical records in release documentation.
