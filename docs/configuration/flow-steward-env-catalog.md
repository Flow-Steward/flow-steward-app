# Flow Steward Environment Catalog
Generated inventory of documented and canonical environment variables. This is the operator-facing catalog: it includes variables from shipped `.env.example*` overlays plus variables in the canonical env manifest. The raw scanner also finds internal shell/test handoff names; those are summarized under audit-only findings instead of being promoted into the user-facing catalog.

Source of truth inputs:
- `core/infrastructure/config/flow_steward_env_manifest.json`
- `docs/configuration/flow-steward-env-audit.json`
- shipped overlays: `.env.example`, `.env.example.prod`, `.env.example.ops`, `.env.example.memory`, `.env.example.test`, `.env.example.quality`

Regenerate with:

```bash
python -m core.application.tooling.ops.generate_env_catalog
```

## Scope Legend
- `Public / Operator`: supported runtime/operator env contracts.
- `Test Config`: documented test and E2E configuration, intentionally separate from operator runtime config.
- `Internal Bridge`: process-to-process handoff env.
- `Internal Runtime`: internal runtime toggles/helpers not intended as normal operator config.
- `Script Internal`: shell-script local env surfaces.
- `Test Only`: test harness variables not part of the canonical manifest.
- `Tooling Internal`: quality/tooling-specific variables.
