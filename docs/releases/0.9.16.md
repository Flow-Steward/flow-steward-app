## Flow Steward 0.9.16

### Command line

- Commands print a readable result instead of JSON; `--json` still gives the machine-readable form. Install, update and upgrade show each step with its time and end with a short summary of what changed.
- Choices are asked one question at a time. The full-screen form and `--tui` are gone.
- Tab completion for bash, zsh and fish, and `flow-steward shell` for provider consoles that have no completion of their own.
- `doctor` exits 0 when it finds only warnings; only a failure exits 4. Maintenance mode switched on by hand is now a warning that names `./flow-steward maintenance disable --confirm`, so `maintenance enable --confirm && release upgrade … --confirm && doctor && maintenance disable --confirm` runs to the end.
- On Docker Desktop, the file-sharing probe file is readable only by its owner.

### Extensions

- Large list responses from an extension, such as a WooCommerce product page with its metadata, no longer fail the reflected-credential check. Repeated strings are compared once, and the check is sized for any output within the default 5 MiB extension output limit.
- A check that cannot finish within its limits now reports `extension_secret_check_incomplete` with the name of the limit, instead of `extension_secret_exposure_blocked`. The output is still blocked in both cases.
- Install and Update clicks in the Marketplace, on the Installed page and on an extension's page wait their turn instead of failing with "Another extension lifecycle operation is already in progress". A waiting button says Queued, then Updating…, then Updated to the new version. An update that needs approval of new permissions lets the next one start while you decide.

### Workflow builder

- Staged structure changes are checked once per change instead of again on every re-render.
- Stop in the run bar reads Cancelling… only after you confirm the stop.
- For each is the only loop. The Inline loop entry in Add step and the "Show as an inline loop" command are gone. Inline loop was only another way to draw a For each, so existing workflows are unchanged.
- Opening a workflow no longer zooms in past 100%. Fit view can still zoom in further.

### Interface

- The approvals bell tooltip no longer adds a horizontal scrollbar, and it hides while the approvals menu is open.
- A long option in a select, combobox or filter menu shows its whole text on hover, as does the chosen value.
- Chart libraries and workflow pages load as separate bundles, so no production chunk is larger than 700 kB.

### Agent skills

- The Operator skill package is 1.1.0. Its workflow migration skill checks the target version's runtime contracts before assembling YAML, ships a bundle preflight script, and covers catalog demand research and catalog delivery.

### Upgrade notes

This release adds no database migration.
