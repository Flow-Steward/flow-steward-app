## Flow Steward 0.9.21

0.9.21 fixes upgrading a Compact installation from 0.9.19 or older. If your
installation already runs 0.9.20, `release upgrade` takes you to 0.9.21 as usual.

### Fixes

- Compact: upgrading from 0.9.19 or older no longer fails at the step after
  `database upgrade`. The migration stops `compact-runtime`. 0.9.20 then read the
  maintenance state through a one-off container, but read Docker Compose's own
  `Container … Creating` lines together with the answer. So `release upgrade` and
  `maintenance status` failed with "Compact maintenance returned an invalid
  result", and retrying did not help. Compose's own messages are now kept apart
  from the answer.

#### Upgrading from 0.9.20 or older

You can upgrade straight to 0.9.21 from any earlier release; every pending
migration is applied in order.

```bash
./flow-steward maintenance enable --confirm
./flow-steward release upgrade --target-version 0.9.21 --confirm
```

An installed CLI older than 0.9.20 may stop with `release_migration_required`
after switching the checkout to 0.9.21. From then on `./flow-steward` is
0.9.21's, so finish with:

```bash
./flow-steward database upgrade --maintenance-confirmed --confirm
./flow-steward release upgrade --target-version 0.9.21 --confirm
```

The finished `release upgrade` disables maintenance itself.

#### An upgrade is stuck after `database upgrade`

This happens when an earlier `release upgrade` failed with "Compact maintenance
returned an invalid result" (0.9.20) or "An unexpected internal error occurred"
(0.9.19 and older, #28), and `./install.sh` answers `release_upgrade_pending`.
Start the runtime on the release you were upgrading to, then repeat that
upgrade:

```bash
cd infra/docker
docker compose -p flow-steward -f docker-compose.compact.yaml -f compact/ingress-bundled_traefik.yaml -f compact/tls-bundled-files.yaml -f compact/storage-bundled.yaml --env-file ../../.env.prod --profile storage-seaweedfs --profile cli up -d --no-deps --no-build --pull never compact-runtime
cd ../..
./flow-steward release upgrade --target-version <the pending version> --confirm
```

Use the project name, compose files and profiles of your installation; they are
in `.flow-steward/compose.env`. Then upgrade to 0.9.21 if the pending version
was older.
