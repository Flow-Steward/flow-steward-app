## Flow Steward 0.9.26

### Features and improvements

- MCP clients can create and edit projects with `project_create` and `project_update`, using the same access rules as the Projects API.

### Fixes

- **Extension installation and updates accept confirmation for the same package.**
  Confirming browser access for extensions such as Google Workspace now continues
  when the same archive is opened again. Core asks for a new confirmation if the
  approved package or its browser access changes.
- **Table search and tooltips.** Table search uses the same clear button as global
  search in light and dark themes. Action tooltips in Extensions stay visible
  above table rows.
- **Clearer duplicate messages.** When an existing name blocks creation, the
  message points to Trash as a place to look for the item.
- **PII redaction preserves distinct values.** When a text contains different
  detected values of the same type, strict redaction assigns distinct markers
  such as `REDACTED_1` and `REDACTED_2`. Repeated values reuse their marker in
  the same text. Pseudonymization applies each value's own pseudonym.
