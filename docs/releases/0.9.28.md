## Flow Steward 0.9.28

### Fixes

- **Keep workflows running after extension updates.** When updating an extension
  from the catalog, an administrator can trust updates from its release
  repository. Flow Steward carries existing stored-secret approvals forward for
  matching connections and workflow steps. Changes to secret bindings, workflow
  definitions or connection destinations still require approval.
- **Keep browser access after installing or updating an extension archive.**
  A browser-access approval survives the archive's publication and subsequent
  rescans of the same release.
- **Package the extension update modules in the runtime images.** The app,
  worker and compact images include the modules needed to retain secret
  approvals across trusted updates.
