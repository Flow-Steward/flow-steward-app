## Flow Steward 0.9.29

### Chat Models

- In **Chat Models**, load current chat-model suggestions available to your OpenAI or Anthropic API key. You can also enter a model ID manually. Flow Steward verifies the selected model when you save the provider. Changing the provider type requires a replacement for any saved key.
- Set up Google Cloud Vertex AI in the Google Cloud Vertex Gemini extension, where model discovery uses your Google Cloud credentials, project and location. Settings still lets you verify or remove existing direct Gemini API-key providers.

### Installation

- Run `./install.sh` from a fresh branch checkout to download the latest stable release. The installer saves the selected version for retries and gives each install directory its own Compose project.
