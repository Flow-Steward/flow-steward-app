## Flow Steward 0.9.29

### Model providers

- Load model suggestions for OpenAI and Anthropic directly from the provider using your API key. You can also enter a model ID manually. Flow Steward verifies the selected model when you save the provider. Changing the provider type requires a replacement for any saved key.
- Set up new Google Cloud Vertex AI connections through the extension catalog. Existing Gemini API key providers can still be edited and verified in Settings.
