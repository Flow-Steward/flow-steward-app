## Flow Steward 0.9.30

### Chat Models

- Fixed model verification and agent calls for OpenAI GPT-6 models, including GPT-6 Luna. These models now use the Responses API for reasoning and tool calls.
- Fixed verification for current Anthropic models, including Claude Haiku 5.5. Verification now uses Anthropic's tool selection and structured output formats, and requests omit sampling parameters on models that do not support them.
